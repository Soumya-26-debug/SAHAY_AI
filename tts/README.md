# SahayAI - Text-to-Speech (TTS)

## Overview

The Text-to-Speech module converts text responses generated by SahayAI
into spoken audio.

This module is mainly useful for users who have difficulty accessing
text-based information, particularly blind or visually impaired users.

SahayAI uses the Piper Text-to-Speech system with a pretrained voice model
for local speech generation.

---

## Role in SahayAI

The TTS module converts the final text response from the AI system into
audio that can be played through the user's device.

User Input
    ↓
STT / Text / Vision
    ↓
